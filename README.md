# Анализ рынка пластиковых исторических миниатюр (Final Assignment FU)

## Цель проекта

Провести комплексный анализ рынка исторических миниатюр (с 1950-х годов по настоящее время) для выявления структурных паттернов, оценки качества продукции и формирования практических рекомендаций для коллекционеров и варгеймеров.

**Объект исследования:** 2 840 наборов пластиковых исторических миниатюр от 61 производителя.

## Ключевые результаты

1. **Рынок высококонцентрирован:** 18 производителей (29,5% брендов) формируют 78,9% всего ассортимента.
2. **Качество стабилизировалось:** Средний рейтинг стабилизировался на уровне 41–42 балла из 50 начиная с 2000-х годов.
3. **Навигация в избыточности:** 81% потенциально «редких» наборов являются условно избыточными — их ниша уже закрыта другими релизами.
4. **Перспективные ниши:** Наибольший рост за 2020–2026 гг. показали темы Italian/Древний мир (+129%), USA/Новейшее время (+116%).
5. **Смена лидеров:** В 1960-х доминировал Airfix, в 2010–2020-х — Strelets.
